# Samraadni — The Royal Weaves of Sahyadri

Premium React + Vite frontend for the Samraadni Maharashtrian heritage brand.

## Included
- React + Vite frontend only
- Samraadni supplied logo
- Supplied campaign/product photography integrated throughout the homepage, collection and Instagram-style gallery
- Deep teal brand background with royal gold accents
- Responsive desktop/tablet/mobile layout
- Sahyadri, gadkille, Swarajya and Maharashtrian heritage visual language
- Collection filtering UI
- Story and contact pages
- Instagram link: https://www.instagram.com/_samraadni_/

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Product names in `src/data.js` are temporary editorial names because final catalogue names/prices were not supplied yet. Replace them there when the final product catalogue is available.
